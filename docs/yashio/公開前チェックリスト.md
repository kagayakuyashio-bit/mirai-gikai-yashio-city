## 2. 外部リンク・チームみらいの記述(確認済み・変更不要)
- `externalLinks` の `donation` / `teamAbout` / `terms` / `privacy` / `faq` は team-mir.ai 等のURLのまま。`showTeamMiraiSection: false` のため、サイトでは表示されない。
- サイトに出ている「チームみらい」の記述は、次の2種類だけ(2026-11-21 に公開サイトで確認)。
  - 「チームみらい開発の『みらい議会』をベースに作成」という出典の明記(トップの About、FAQ。元サイトへのリンクつき)
  - 「チームみらいの公式ではない非公式サイト」という断り書き(トップ、FAQ、利用規約、プライバシーポリシー、フッター)
- 非公式であることを示す大事な表示なので、消さずに残す。

## 5. 機能の状態
- web: `features.aiChat = false` / `features.aiInterview = false`
  - AIインタビュー関連ページ(`/bills/*/interview`、`/opinions`、`/report`)は middleware で404
  - `/api/chat`、`/api/interview/*` は404、サーバー側処理も実行前に例外で停止
- admin: `features.ai = false`
  - AI情報収集・インタビュー設定・レポート・トピック解析のページ/APIは middleware で404
  - Claude CLI / AI Gateway を呼ぶ処理は実行前に例外で停止。関連ボタンは非表示
- AIを有効にする場合は上記フラグをtrueにし、`.env` のAPIキーを設定する
