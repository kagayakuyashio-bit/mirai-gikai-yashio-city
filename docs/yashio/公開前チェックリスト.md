## 5. 機能の状態
- web: `features.aiChat = false` / `features.aiInterview = false`
  - AIインタビュー関連ページ(`/bills/*/interview`、`/opinions`、`/report`)は middleware で404
  - `/api/chat`、`/api/interview/*` は404、サーバー側処理も実行前に例外で停止
- admin: `features.ai = false`
  - AI情報収集・インタビュー設定・レポート・トピック解析のページ/APIは middleware で404
  - Claude CLI / AI Gateway を呼ぶ処理は実行前に例外で停止。関連ボタンは非表示
- AIを有効にする場合は上記フラグをtrueにし、`.env` のAPIキーを設定する
